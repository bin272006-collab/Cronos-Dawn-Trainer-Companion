## 🌌 Overview

**Cronos: New Dawn** is a title that rewards patience, precision, and a certain willingness to lose yourself in its layered environments. The **Trainer Companion Hub** exists for one reason: to give adventurers a single, dependable location where configuration insights, tuning walkthroughs, and companion utilities are organized rather than scattered across forgotten forum threads.

Whether you are running the game on a modest laptop or a fully decked-out battle station, this hub adapts. Every document here is written with clarity as the north star — no dead ends, no vague hints, no closed doors. Consider this repository the well-worn map folded into your back pocket, ready whenever the road ahead turns strange.

This is not a shortcut. It is a **companion layer** — a set of thoughtful enhancements, notes, and overlays that sit alongside the game and help you shape your own experience.

---

## 🧭 The Philosophy Behind the Hub

Most utility repositories treat players as a monolith. We reject that. A player on a low-spec Windows 10 machine fighting for 30 stable frames has entirely different needs than a Windows 11 enthusiast chasing pixel-perfect overlays on an ultrawide panel.

So we built the hub around three pillars:

1. **Clarity over cleverness** — every guide assumes you are intelligent but new. No jargon gates.
2. **Reversibility** — every tweak described here can be undone with equal ease. Nothing is permanent unless you choose it.
3. **Respect for the world** — the experience of Cronos: New Dawn is the point. The hub exists to remove friction, not to replace the journey.

## 📱 Responsive Interface Design

The companion interface was designed from a **fluid-first** mindset. Instead of assuming a single canonical window size, every panel measures its own container and reflows accordingly. On a 13-inch laptop display, widgets collapse into a tidy vertical stack. On a triple-monitor setup, they fan out into a dashboard that reads at a glance.

Key responsiveness principles applied:

- **Breakpoint-driven reflow** — layout density shifts cleanly at common display widths.
- **Aspect-aware scaling** — 16:9, 16:10, 21:9, and 32:9 are all first-class citizens.
- **DPI-relative sizing** — high-DPI panels stay sharp without blurry upscaling.
- **Keyboard-friendly navigation** — every interactive element reaches through tab order.
- **Motion-sensitivity option** — animations can be softened for players who prefer calm interfaces.

The result is a companion that feels native no matter where it runs.

## ⚙️ Performance & System Notes

The hub is tested primarily against **Windows 11** and **Windows 10**, with attention paid to how each platform handles display scaling, window composition, and background services.

Recommended baseline expectations:

- **Processor:** A modern dual-core or better.
- **Memory:** 8 GB recommended for smooth overlay coexistence.
- **Graphics:** Hardware capable of DirectX 11 feature level or newer.
- **Storage:** A few megabytes for the hub itself; the game's own footprint is separate.
- **Display:** 1280×720 minimum; 1920×1080 and beyond strongly preferred.

We do not promise magic. We promise measured, documented, and reversible tuning.

## ❓ Frequently Explored Topics

**Is this compatible with both Windows 11 and Windows 10?**
Yes. Both are treated as first-class platforms, with platform-specific notes where behavior diverges.

**Will the hub affect my save data?**
No. This companion focuses on presentation and configuration guidance. It does not touch progress files.

**What if a new game patch breaks something?**
The `/docs` folder tracks known compatibility notes after each major update. Check there first.

**Can I run only a subset of features?**
Absolutely. Every overlay component and profile is opt-in. Enable what serves you, skip the rest.

**Does the interface work on ultrawide monitors?**
Yes — aspect-aware scaling includes 21:9 and 32:9 configurations.

**How often is documentation refreshed?**
As often as the game and community require; the 2026 roadmap below outlines the cadence.
